# STEMLab — Laboratorio interactivo de física y matemáticas

Aprende física tocando las variables: simulaciones en vivo con canvas, retos con puntaje y explicaciones paso a paso. Sin cuentas, sin instalar nada.

## Laboratorios

- **Tiro parabólico** — velocidad, ángulo y gravedad por planeta (Luna, Marte, Tierra, Júpiter) con trayectoria prevista, datos en vivo y fórmulas sustituidas.
- **Péndulo simple** — integración numérica real, periodo teórico vs medido, vectores de velocidad y aceleración.
- **Ley de Ohm** — circuitos en serie y paralelo, electrones animados según la corriente y bombillo que brilla según la potencia.

## Retos

12 preguntas cronometradas (tiro parabólico, péndulo, Ley de Ohm) con puntaje, bonus por rapidez, explicación inmediata y mejor puntaje guardado en el dispositivo.

## Tecnología

Next.js 16 (App Router) + TypeScript estricto + React 19. Física calculada en el cliente con Canvas 2D y requestAnimationFrame. Sin backend ni claves: todo corre en el navegador.

## Desarrollo

```bash
npm install
npm run dev
```
